# NO_CHECKOUT — TrainerHub

**Hard rule:** **no in-site checkout**. Payment is **off-site only**.

## Allowed

- Honest offer page with proposed ILS 59 (unvalidated)
- Access code after **off-site** payment (Bit / PayBox / bank transfer)
- Demo boundary code `TH-MAAMEN-59` (product boundary, not security)

## Forbidden

- Stripe / PayPal / embedded card forms on Pages
- Auto-renewing subscriptions in this static demo
- Fake registrant / subscriber counts
- Treating the demo access code as proof of payment

Hebrew: אין סליקה באתר — payment off-site only.

## SOP (when selling)

1. Buyer pays off-site (Bit / PayBox / transfer)
2. Owner issues a unique access code (not the public demo code)
3. Trainer redeems code in the browser entitlement gate

See MONETIZATION.md and offer.html.
