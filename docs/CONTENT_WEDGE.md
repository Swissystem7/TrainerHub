# Content wedge — TrainerHub (CRM = PARK)

**SKU:** content-only — Hebrew exercise library + weekly builder + client share/PDF.
**CRM track:** **PARK** (do not build journal/billing/WhatsApp server/client DB).

## What this SKU is

| In scope | Out of scope |
| --- | --- |
| Clip library (catalog / Releases) | Client CRM / roster management |
| Weekly plan builder | In-app checkout / subscriptions |
| Share hash links + print/PDF | Live SaaS backend on Pages |
| Demo access-code boundary (`TH-MAAMEN-59`) | Competing on clip count vs AutoFit/Coach |

## Pricing stance

Proposed **ILS 59 / trainer seat / month** for the content-only path — **not interview-validated**. See `MONETIZATION.md`.

## Why PARK on CRM

Israeli PT CRMs already cover Hebrew + management (AutoFit / Coach / Boostapp / Tazman). TrainerHub’s honest wedge is **תוכן בלבד** (content only), not another CRM.

## Gate

Run the 10 PT WTP interviews before treating ILS 59 as validated. If buyers demand journal/CRM, that is scope creep — keep CRM **PARK**.
