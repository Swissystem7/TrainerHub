## 10-interview kill criteria checklist

Use this before treating the ₪59 / ILS 59 trainer SKU as validated demand.

- [ ] **1.** Book **10 interviews** with independent personal trainers (PTs) who are not friends/family of the owner.
- [ ] **2.** Ask whether they already get Hebrew exercise library + share/PDF inside AutoFit / Coach / Boostapp (or similar CRM).
- [ ] **3.** Ask whether they would pay for a **library + builder without a journal/CRM**.
- [ ] **4.** Record a clear yes / no / maybe on willingness to pay near **ILS 59 / month per trainer seat**.
- [ ] **5.** Count how many of the 10 say “I already have this in AutoFit/Coach” **or** “I will not pay for a library without a journal”.
- [ ] **6.** **Kill rule:** if **≥6 / 10** give that answer — **close the content wedge**; do not keep selling the SKU.
- [ ] **7.** Keep a one-month visible offer live (e.g. `offer.html`) with an honest proposed price — no fake registrant counts.
- [ ] **8.** Track access-code requests for demo code `TH-MAAMEN-59` (product boundary, not security).
- [ ] **9.** **Kill rule:** after **1 month** of a visible offer with **zero** access-code requests — no demand at this price; stop selling the SKU.
- [ ] **10.** Do **not** compete on clip count (78 vs 2,000–10,000). Only honest differentiator: Hebrew + light tool + no CRM.
